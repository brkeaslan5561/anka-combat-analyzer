# Anka Combat Analyzer v1.0.0

İlk herkese açık Windows sürümü.

## Öne çıkanlar

- Neverwinter combat log dosyasını yükleme ve dosya değiştikçe canlı analiz
- Encounter, oyuncu, güç, healing, tanking, mitigation ve death incelemeleri
- Oyuncu/pet ayrımı ve companion hasarını isteğe bağlı bölme
- Düşman güçlerinin düzenli tekrar aralıklarını bulma ve özelleştirilebilir timer overlay'i
- ACT yaklaşımını koruyan, kompakt ve modern analiz arayüzü
- Anka temasından esinlenen özel Windows uygulama ikonu

## İndirme

- `Anka-Combat-Analyzer-Setup-1.0.0-x64.exe`: normal Windows kurulumu
- `Anka-Combat-Analyzer-Portable-1.0.0-x64.exe`: kurulum gerektirmeyen sürüm

Bu sürüm kod imzalama sertifikasıyla imzalanmamıştır. Windows SmartScreen ilk çalıştırmada “Bilinmeyen yayıncı” uyarısı gösterebilir. İndirdiğiniz dosyayı `SHA256SUMS.txt` ile doğrulayabilirsiniz.
