# Anka Combat Analyzer v1.1.16

Bu sürüm soldaki encounter ağacında run gruplarının daha rahat yönetilmesini sağlar.

## Açılır/kapanır run grupları

- Run başlıklarına tıklayarak altındaki encounter listesi açılıp kapatılabilir.
- Sol taraftaki ok simgesi run'ın açık veya kapalı durumuna göre değişir.
- Run başlığına tıklanınca o run'ın toplam analiz kapsamı seçilmeye devam eder.
- Yeni bir combat log açıldığında run grupları varsayılan olarak açık başlar.
- Açılır/kapanır alanlara erişilebilirlik bilgileri eklendi.

## Doğrulama

- Run katlama davranışı için regresyon testi eklendi.
- Type-check, test ve production build kontrolleri çalıştırıldı.

## İndirme

- `Anka-Combat-Analyzer-Setup-1.1.16-x64.exe`
- `Anka-Combat-Analyzer-Portable-1.1.16-x64.exe`

Bu sürüm kod imzalama sertifikasıyla imzalanmamıştır. Windows SmartScreen ilk manuel kurulumda “Bilinmeyen yayıncı” uyarısı gösterebilir.
